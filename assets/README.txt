ASSETS FOLDER — Mairhofer Advokatur
=====================================

/assets
  /images          — All photos and static images
    logo.svg             Logo (SVG preferred, PNG as fallback)
    logo-light.svg       Light variant of logo (if needed)
    hero-poster.jpg      Static fallback shown before hero video loads
    about-office.jpg     Office/architecture photo used in About section
    office-schaan.jpg    Office photo for Contact card (Schaan)
    team-remo.jpg        Portrait photo of Remo Mairhofer
    badge-bar.svg        Liechtenstein Bar Association membership badge (or PNG)

  /video           — Hero background video
    hero.mp4             Autoplay hero loop (dark/cinematic ambient clip)
    hero.webm            WebM version for better browser compatibility

  /icons           — SVG icons and favicon files
    favicon.ico
    favicon.svg
    apple-touch-icon.png

  /fonts           — Self-hosted fonts (optional, only if not using Google Fonts)


NAMING CONVENTIONS
------------------
- Use lowercase, hyphens only — no spaces, no underscores
- Photos: descriptive-name.jpg (e.g. office-schaan.jpg)
- Logos/badges: badge-name.svg or logo-name.svg
- Keep originals at full resolution; the browser handles display sizing
